# Changelog

All notable changes to this portfolio system will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

## [3.0.0] - 2026-09-29

### Added
- **Monochrome Computational Minimalism System**: Visual ratio locked to 80% Black (`#000000`, `#050505`) and 20% White (`#FFFFFF`).
- **Signature Computational Topology**: Phased vector animation in `assets/hero.svg` representing neural and distributed DAG systems (Boot &rarr; Network Formation &rarr; Data Routing &rarr; Stable State).
- **Engineering Manifesto Panel**: `assets/focus.svg` structuring the 6 core capability tiers with an environmental bus signal.
- **Self-Hosted Telemetry**: `assets/activity.svg` with animated commit trajectory curve and core runtime distribution metrics.
- **Repository Governance**: Codified `.agents/rules/editorial-portfolio-design.md` enforcing the 80/20 black/white design invariants.
- **Version Tracking**: Added `VERSION` file and changelog tracking.

### Changed
- **Profile Architecture**: Refocused `README.md` strictly on *Identity &rarr; Focus &rarr; Technology &rarr; Activity &rarr; Exploring &rarr; Connect*.
- **Asset Modernization**: Replaced third-party dynamic badges and SVG services with self-hosted, 100% valid XML SVGs.

### Removed
- Removed redundant project showcase section to prevent duplication with pinned repositories.
- Deleted legacy animated typing headers, capsule wave banners, trophies, streak counters, and snake games.
